browser.tsx: 默认浏览器状态与「一键设为默认浏览器」（触发系统确认）、指纹与代理配置、Default 资料缓存清理、跟随目标地区的真实观测核验与显式机器对齐；站点永久删除使用 Alert 警告并默认取消；复用 Cromma UI 和活动日志。
browser-model.ts: 工具箱与起始页共享配置、目标地区、机器、出口服务目录、观测接收时间与默认浏览器契约，不接入原生权限；三平台设备/CPU/版本核验由共用函数保持一致，Windows 必须 Win32。
browser-start.tsx: 实际 navigator/Intl/Permissions 与 HTTPS 出口上报，心跳和回报时间显示本机通讯状态；已测项目全部匹配、回传成功且无错误时显示整页绿背景与大对勾，重测或断连取消成功状态；随机令牌回环服务隔离宿主命令。
browser-network.ts: 按宿主服务目录经浏览器当前路由检测出口，限流/故障切换服务，校验结果并保留失败原因。
browser-network.test.ts: 模拟限流、备用响应与非法出口，验证故障恢复和错误信息，不访问外网。
main.tsx: Guard 品牌与单窗口极简侧栏；Guard 保护页默认打开，保留傻瓜设置、网络环境、Claude 身份管理、浏览器环境、电脑环境和使用说明；只显示当前版本，不调用自动或官方更新器；静态预览不调用 Tauri API。
guard-home.tsx: 通过 guard_status/guard_inspect/guard_start/guard_lock/guard_recover 呈现原生快照、目标原因、环境观测与有界事件；闲置时轮询状态，Lock 可优先打断其他 Guard 命令，旧响应不能覆盖新锁定快照；准备/恢复前说明出口 HTTPS 探测服务可见代理 IP；动态探测诊断保留错误码、耗时与超时来源并在呈现时翻译，失败记录显示记录时间；静态预览禁用命令。
guard-model.ts: Guard snapshot schema（兼容旧事件及新增记录时间）、由原生 available 字段决定目标启动可用性、状态按钮条件与最新请求判定；Unavailable 允许显式准备/恢复。
guard-model.test.ts: 纯逻辑验证初始 unavailable、目标/状态按钮门槛、原生目标可用性、旧响应丢弃及快照结构；不调用 Tauri 或网络。
help.tsx: 双语只读说明页，顶部常显旅居人员本人身份管理与禁止违反官方用户协议的声明；五项编号行保留操作后果和删除提示，details 折叠账号边界/申诉，不读取用户资料或调用原生命令。
identities.tsx: 空身份固定最左、当前账号其次的竖式 196×312 工牌，单排横向卡片，顶部挂孔绿光表示当前身份、无障碍名称保留状态语义；Motion 弹簧滚轮/轻微悬停视差（按钮区冻结，卡片内部保持平面命中测试），原生媒体订阅使减弱动态偏好实时停止动画；滚动条/键盘保持原生，无分页或数量截断；卡片直接切换、折叠保留选项、名称、切换/恢复/永久删除 Alert 警告（需勾选确认，默认聚焦取消）；只调用受限原生身份命令，凭据不进 UI。
identity-model.ts: SQLite 受限目录、当前显示字段和保留策略契约，Skills/插件/MCP/个人设置/项目记录/历史/缓存逐项由用户选择。
claude-cli-panel.tsx: 身份页内的 CLI 维护；复用安全进程结束和官方卸载/重装，保护保险库与个人资料。
cleaner-activity.tsx: 身份暂存/切换/直接删除、CLI 安装与其他事务的单次调用进度通道、实际进度、耗时与默认收起的有界日志；保留原始消息供即时切换语言，不参与修改决策。
