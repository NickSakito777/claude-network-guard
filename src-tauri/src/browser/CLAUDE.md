mod.rs: Tauri 浏览器命令、单次变更锁与运行时状态；配置保存、启动、清理、换指纹和默认浏览器注册要求 CCBaga Browser 防护已核验；系统对齐要求当前全部可用 Guard 目标覆盖；宿主/URI 启动入口在写 launch.args、start.url、资料偏好或启动 Chromium 前执行同一闸门；只读状态与环境观测保持可用；退出仍用于安全停止浏览器。
config.rs: 指纹配置（新资料默认代理留空以跟随 TUN）、实际机器参数、代理/地区语言白名单和 Chromium 参数生成；明确启动 Default 资料，防止最近使用资料与清理/偏好范围错位，品牌版本采用实际引擎版本。
profile.rs: 独立资料目录、进程占用检查、偏好窄范围写入与缓存清理；登录数据单独明确选择，旧/新两种定位偏好同时禁用。
network.rs: macOS/Linux/Windows 原生平台与浏览器观测分别核验，Windows 识别 Win32 并要求真实版本/CPU；共用 ipwho.is/ipapi.co 服务目录；经同一指定代理检测出口，服务故障/限流按顺序备援，分块限定响应规模并报告 HTTP 原因；本机出口对比；按共用目录匹配目标国家/语言/区域；失败、国家/语言/区域或时区冲突均不显示通过，自定义地区未知时保持未核验。
server.rs: 随机令牌回环服务，刷新实际机器与界面语言上下文，接收浏览器观测并提供同令牌只读回报/接收时间，供实际 A/B 启动验收，CSP 仅放行两个已选出口服务；存活到会话令牌被替换或清空；静态资源限制在打包目录。
windows.rs: Windows 引擎和共同资料/回环会话编排；用户点击后注册完整默认浏览器协议，不改写默认关联；B 启动项进入同一宿主，CI 启动阶段只记录固定字符串；CI 实际核验注册命令/两个协议，前后默认关联必须不变。
tests.rs: 模块共用临时目录样本，验证代理/资料边界、缓存隔离与地区核验；本机 HTTP 样本复现 429 并核验备援解析，Windows 使用真实 junction 样本验证拒绝跨资料目录；不触碰现有账号数据。
linux.rs: Linux libexec 隔离引擎（兼容源码/Arch 的资源目录），带双布局路径回归，与宿主驱动的 CCBaga-B 启动项；处理 --browser 链接、同资料重连、显式 xdg-mime 注册并核验 HTTP/HTTPS；定位状态未知的桌面禁止完整机器对齐，修改前停止；Linux UA 不提供内核版本，不用 UA 值伪装内核核验。

workspaces.rs: 同库身份资料选择、独立种子与事务启动阻断；失败保留pending，成功准备后仍需Guard有效运行授权。
