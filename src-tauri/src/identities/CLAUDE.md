# identities/
> L2 | 父级: ../CLAUDE.md
mod.rs: 当前/空/已保存身份与切换/恢复/重命名/直接删除、浏览器联动 Tauri 命令，复用 Cleaner 操作租约；切换/恢复和当前身份删除要求 Claude Guard 目标授权，浏览器联动配置要求浏览器 Guard 目标授权；UI 接收目录元数据、绑定摘要与白名单账号显示字段，令牌不送 UI。
database.rs: 内嵌 SQLite 管理身份目录、HMAC 账号索引和浏览器资料槽/种子；v1→v3 事务迁移，身份归档指针、浏览器指针和 recovery 标记同事务更新，FULL 同步，凭据正文不入库。
browser_link.rs: 同一身份数据库中的联动状态、独占资料槽绑定和非零稳定种子；账号摘要只返回受限展示字段，恢复期间选择指针可事务回退。
catalog.rs: 本机 HMAC 账号匹配、旧归档核验索引与提交后代次回收；不按展示名称或 token 匹配，不自动合并未知或损坏归档。
store.rs: Gzip 加密归档、不可变归档代次和 SQLite 协调的切换/失败恢复与明确的无新增备份删除；归档绑定平台、用户目录和本机保险库密钥，不声称抵抗用户自行复制全部密钥与数据。
profile.rs: 只读默认 .claude.json 的用户名/邮箱/组织显示白名单，API Key 仅记存在性、桌面仅检查身份路径元数据；不可读不冒充空身份，不读取钥匙串或 Cookie 正文。
credentials.rs: 默认 Code 凭据按用户策略合并身份与共享 MCP/插件秘密；正文只在原生内存流动。
codec.rs: tar/gzip 流与 ring AES-256-GCM 帧，独立归档密钥和认证结尾；拒绝篡改、截断与非法归档成员。
private.rs: POSIX 0700/0600 与 Windows 创建时指定当前用户所有者/独占 DACL、原子写入；拒绝所有者变化、链接和特殊文件。
tests.rs: 临时账号/会话样本的空身份、恢复、配置保留、损坏与链接拒绝和未完成事务恢复、选择性永久删除与跨策略恢复、缺失主密钥拒绝，沿用原生 dunce/标准库规则并断言临时文件的规范路径、使用同一私有创建层模拟管理员文件所有者，不接触真实账号。
browser_link_tests.rs: 临时 SQLite 对联动默认值、槽/种子唯一性、切换提交与失败回滚、资料指针恢复、摘要脱敏和 v2 迁移的离线测试。
optimization_tests.rs: 临时账号/归档样本对 HMAC 匹配、A/B 切换、刷新凭据、不可变代次提交/拒绝更新、Gzip 认证边界和 v1 迁移的离线测试；不包含性能基准或真实用户数据。
